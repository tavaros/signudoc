# Sample policies

Short starting points for the policies a SOC 2 auditor asks to see, written for an organization that runs a SignuDoc install. They are not legal advice and not complete policies for your whole organization: fold them into your own policy set, fill in each `[bracket]`, have them approved, and review them yearly.

| Policy                                              | Criteria          |
| --------------------------------------------------- | ----------------- |
| [Access control](access-control.md)                 | CC6.1 to CC6.3    |
| [Change management](change-management.md)           | CC8.1             |
| [Logging and monitoring](logging-and-monitoring.md) | CC4, CC7.2        |
| [Incident response](incident-response.md)           | CC7.3 to CC7.5    |
| [Backup and recovery](backup-and-recovery.md)       | CC9.1, A1.2, A1.3 |
| [Data retention](data-retention.md)                 | CC6.5, C1.2       |
| [Vendor management](vendor-management.md)           | CC9.2             |

Each says who owns it, what must happen, and what evidence shows it did.
