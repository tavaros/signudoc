# Vendor management policy

**Owner:** `[security owner]`.

1. Before a new vendor holds our data or runs part of the install, `[role]` reviews its security report, terms and data processing agreement, and records the result ([Vendor duties](../vendor-duties.md#vendor-review-record)).
2. Every `[year]`, `[role]` reviews each vendor's current SOC 2 report (period, opinion, exceptions), checks we still meet the complementary user entity controls it lists, and records the review.
3. A vendor's incident notice is handled under the [incident response policy](incident-response.md).
4. Billing for every vendor is kept current, and on a company card owned by `[role]`, so a lapsed payment cannot take records offline.
5. SignuDoc itself is reviewed as an open-source component: each release is read before it is taken ([change management](change-management.md)).

**Evidence:** vendor review records, current reports on file.
